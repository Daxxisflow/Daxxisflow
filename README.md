# Daxxis

I run a one-person operations shop and document how a solo operator builds a local-first AI home: one workstation that keeps the records, verifies every AI worker's output, and never sends a secret to a platform.

- Field guides: *The 3-Tier Vault* on Leanpub (how to split business, personal and sealed material across encrypted containers).
- Tools: `daxxis-tools` (Windows OCR without installs, a loopback-pinned Ollama launcher, a volume guard for scheduled tasks).
- Contact: github@daxxisflow.com

Everything here is MIT unless a file says otherwise. No telemetry, no accounts, nothing phones home.
